# Chian Yee's Journey

My interactive portfolio, built for recruiters and hiring managers:

1. **Hero & About:** who I am, what I'm looking for, skills, education.
2. **Journey Map:** every project from 2024 to 2026 on a winding trail. Hover or tap a stop for details.
3. **Explore Mode:** a walkable 2D campus with one classroom per year, where I (a chibi version of me) introduce each project. It also has a Skills Tree, day/night lighting, a hidden retro console with Snake, and optional lo-fi music.

**Stack:** Vite · React 19 · TypeScript · Tailwind CSS v4 · Motion. Explore Mode is a small custom engine that draws everything as SVG: crisp at any zoom and about 20 KB, loaded only when someone clicks Explore. Deployed on **Vercel**.

Lighthouse (production build): **mobile 97 / 100 / 100 / 100, desktop 100 / 100 / 100 / 100** (performance / accessibility / best practices / SEO).

## Edit content

All text lives in `src/data/`. You never need to touch the components.

| File | What's in it |
|---|---|
| `src/data/profile.ts` | Name, tagline, availability badge, Quick profile rows, About paragraphs, skills, Skills Tree badges, education, certifications, languages, fun facts, links |
| `src/data/projects.ts` | Every project. It feeds the Journey Map, the classrooms, the "Skip the tour" list and the detail panels |
| `src/data/dialogue.ts` | What I say in Explore Mode (tutorial, room intros, Skills Tree, console) |

Search the code for `TODO(Cheryl)` to find placeholders still waiting for your words. Detail-panel bullets that start with `TODO` are hidden automatically.

### Add a project
1. Copy an existing entry in `src/data/projects.ts` and give it a unique `id`.
2. Set `year` (2024 / 2025 / 2026) to choose its classroom, and `start` (`"YYYY-MM"`) to place it in time order.
3. Fill in `title`, `shortTitle` (for map labels), `role`, `dateLabel`, `summary` (1–2 lines), `keyResult`, `details` (bullets), `tags`, `links` and `emceeLine` (what I say at the desk).
4. Pick an `icon`: `puzzle`, `scale`, `blocks`, `clipboard`, `dna`, `chat`, `trophy`, `clock`, `cloud`, `plus`, `star`, `chart`, `compass`, `target`… (see `src/components/icons.tsx`).
5. Optional: `featured: true` gives it a larger stop and a whiteboard in its classroom; `comingSoon: true` shows the under-construction desk.

The trail, the classroom desks and the lists all update automatically.

### Add screenshots, GIFs and videos
Put files in `public/media/projects/<project-id>/` and list them on the project:

```ts
images: [
  { src: "/media/projects/timewise-engine/gantt-chart.png", alt: "My TeamGantt plan with milestones" },
  { src: "/media/projects/fit5222-train-scheduling/trains.mp4", alt: "Trains replanning around a breakdown" },
],
```

- Images: `.png`, `.jpg`, `.webp` or `.gif`. Videos: `.mp4` or `.webm` (they autoplay muted and loop, with controls). Optional `poster: "/media/…/frame.png"` for videos.
- Keep images under ~1600px wide / 300 KB and videos under ~10 MB (GitHub refuses files over 100 MB).
- If a file is missing, the panel shows a "coming soon" placeholder instead of a broken image, so you can set `src` first and add the file later.
- Never upload coursework code, notebooks or reports, or anything showing teammates' names or student IDs.

### Resumes
Put these two files in `public/` (the names must match exactly):
- `On_Chian_Yee_Resume_Product_Management.pdf`
- `On_Chian_Yee_Resume_Data_Science.pdf`

### Colours and theme
All colours are variables in `src/index.css`. The site uses the **light** theme. Three ready-made dark themes (`midnight`, `graphite`, `forest`) are also defined there: switch with `data-theme="…"` on `<html>` in `index.html`.

### Restyle or swap the character
The chibi me is drawn in code in `src/character/emcee.ts`:
- **Change colours** (hair, outfit, leaf pin…) in the `palette` at the top.
- **Change the shapes** in the `front` / `back` / `side` functions. Check the result on the preview sheet (`/dev/character.html`).
- **Use your own artwork instead:** make `emceeMarkup()` return your art for each `dir` (down/up/left/right), `pose` (idle/walk/wave/talk) and `frame` (0–3). Any SVG works, or an `<image href="/media/character/…png">` inside one. Everything else picks it up automatically.

### Social preview image
`public/og-image.png` (1200×630) and `public/apple-touch-icon.png` are generated by a script. After changing your name or tagline, regenerate them (uses your system fonts):

```bash
npm run og
```

## Deploy (Vercel)

**First time**
1. Create an **empty** repository on GitHub (no README), e.g. `chian-yee-journey`.
2. Push this folder:
   ```bash
   git add .
   git commit -m "Portfolio"
   git branch -M main
   git remote add origin https://github.com/chianyee32/chian-yee-journey.git
   git push -u origin main
   ```
3. Sign in at [vercel.com](https://vercel.com) with GitHub → **Add New… → Project** → import the repo → **Deploy**. Vercel detects Vite automatically (settings also live in `vercel.json`).

**Every update after that**
```bash
git add .
git commit -m "Describe the change"
git push
```
Vercel rebuilds and redeploys within a minute. Pushes to other branches get their own preview URL.

**Custom domain (optional):** add it in Vercel → Project → Settings → Domains. To make link previews use it, add an environment variable `SITE_URL=https://your-domain.com` in the same settings and redeploy. Without it, previews use the Vercel production URL automatically.

## Project structure

```
src/
  data/            ← all content (edit these)
  character/       ← the chibi character, drawn as SVG
  components/      ← main page: Hero, About, Skills, Journey, backgrounds, icons
  explore/         ← Explore Mode (lazy-loaded)
    engine.ts      ← movement, collisions, camera, interactions
    scenes.tsx     ← campus + classroom layouts (generated from data)
    art.tsx        ← SVG props: buildings, desks, trees, console…
    ambient.tsx    ← Skills Tree, day/night lighting, skills list, Snake
    music.ts       ← generated lo-fi music (Web Audio)
    ui.tsx         ← panels, map, speech box, joystick
public/            ← favicon, preview image, resumes, project screenshots
scripts/make-og.mjs← generates the social preview image + app icon
```

## Accessibility

- Keyboard: skip link, visible focus, every control reachable. Explore Mode: arrows/WASD to move, **E** to interact, **M** map, **V** zoom out, **Esc** to close or leave.
- **Skip the tour** lists every project as plain, screen-reader-friendly content.
- Panels trap focus while open and restore it when closed. Prompts are announced.
- All animation (scroll reveals, hero network, Skills Tree, lighting effects, typing text) stops when the visitor asks for reduced motion.
- Text colours meet WCAG AA contrast.
